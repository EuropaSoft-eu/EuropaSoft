3. Politique de confidentialité & Absence de collecte

Engagement fondamental : EuropaSoft applique un principe strict de minimisation et de non-ingérence.

  • Zéro traceur, zéro cookie : Aucun cookie publicitaire, d'analyse ou de pistage n'est généré ni stocké lors de votre visite.
  • Zéro appel tiers : Le site n'inclut aucune bibliothèque distante, aucun réseau CDN externe, aucune police hébergée ailleurs ni pixel espion.
  • Stockage local (PWA) : Le cache du Service Worker et la préférence de thème (clair/sombre) résident exclusivement dans la mémoire locale de votre navigateur. Rien n'est jamais transmis à un serveur.
  • Applications autonomes : Les logiciels édités (Clio, Calliope, Le Chasseur de Champignons, Morphée) conservent l'intégralité de leurs documents, notes et données sur votre machine ou appareil.

4. Propriété intellectuelle

Les marques, logos et identités visuelles d'EuropaSoft ainsi que le code source du site sont régis par leurs licences respectives (licence MIT pour le code source public du site). Les textes et créations originales demeurent la propriété exclusive de leur auteur.
