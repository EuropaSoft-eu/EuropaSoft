# EuropaSoft — Product Brief

## Identity

**Product:** EuropaSoft App Distribution Platform  
**Type:** Web showcase + distribution hub  
**Platform:** Web (HTML/CSS/JS vanille)  
**Mode:** Experience (showcase-led, interface recedes)  
**Owner:** Yoann Cramatte  
**Company:** EuropaSoft

## Purpose

Platform showcase & distribution pour apps EuropaSoft. Visiteurs découvrent, explorent, téléchargent ou lancent apps en ligne.

## Users

- **Primary:** Chercheurs d'apps (grand public + professionnels)
- **Behavior:** Browse catalogue → explore app details → télécharge/lance
- **Devices:** Desktop + mobile + tablet

## Core Apps (MVP)

| App | Type | Versions | Model | Notes |
|-----|------|----------|-------|-------|
| **Clio** | Productivity | Web (limité) + Desktop (Windows/Mac/Linux) | Freemium | Base gratuit, features complètes desktop |
| **Chasseur de Champignons** | Utilities | Mobile (iOS + Android) | Gratuit | Mobile-only, outdoor app |
| **Collectiv'City** | Professional | Web + Desktop (Windows/Mac/Linux) + Mobile (iOS + Android) | Freemium modulaire | Collectivités locales, modules payants |

## Visual World

**Logo & Branding:** EuropaSoft logo fourni  
**Color Palette:**
- Primary: Bleu marine/foncé (#003F7F–#004A8D)
- Secondary: Bleu ciel/cyan (#0099CC–#00A8E8)
- Accent: Jaune/Or (#FFD700–#FFC107)
- Neutrals: Blanc, grises légères

**Typography:** Sans-serif moderne (Montserrat, Poppins, Inter, ou système)  
**Tone:** Professionnel, premium, tech-forward, accessible

## Key Experiences

1. **Homepage:** Hero + app showcase (cards/grid)
2. **App Detail Page:** Description + vidéo/screenshots + liens téléchargement/lancer
3. **Catalogue:** Browse, filtrer (type, OS, gratuit/payant)
4. **Download Flows:** Directs vers versions (Windows/Mac/Linux/iOS/Android)
5. **Web Launch:** Ouvrir app vanilla directement navigateur

## Success Metrics

- Visiteurs voient apps clairement
- Trouvent liens téléchargement/lancement rapidement
- Design premium inspire confiance
- Mobile responsive impeccable

## Out of Scope (MVP)

- Comptes utilisateurs
- Système paiement intégré
- Analytics/dashboard
- Blog/documentation
- Social features
